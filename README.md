# 스마트 광고 AR 시스템

웹 기반 실시간 OCR 및 개인화 광고 오버레이 시스템

## 개요

물리적 광고판을 촬영하면 OCR로 텍스트를 인식하고, 사용자의 페르소나에 맞춘 개인화된 정보를 CSS 오버레이로 실시간 표시하는 AR 시스템입니다.

**핵심 특징:**
- 웹 기반 아키텍처 (PC ↔ 스마트폰 실시간 동기화)
- PaddleOCR 한국어 텍스트 인식
- 페르소나 기반 개인화 엔진
- CSS 기반 고품질 오버레이
- HTTPS 지원 (스마트폰 카메라 접근)

## 시스템 구조

```
┌─────────────────┐         ┌──────────────────┐
│   PC 관리 페이지  │ HTTPS   │  스마트폰 AR 뷰   │
│  (페르소나 설정)  │ ◄─────► │  (카메라 촬영)   │
└─────────────────┘         └──────────────────┘
         │                           │
         └───────────┬───────────────┘
                     ▼
            ┌─────────────────┐
            │  Flask 백엔드    │
            │  - OCR 처리     │
            │  - 개인화 로직  │
            │  - 프로필 관리  │
            └─────────────────┘
```

## 주요 기능

### 1. 실시간 OCR 텍스트 인식
- **PaddleOCR** 한국어 특화 모델 사용
- 광고판의 메뉴명, 가격, 프로모션 텍스트 자동 인식
- 20프레임마다 OCR 실행 (CPU 부하 최적화)

### 2. 페르소나 기반 개인화
- **프리셋 페르소나**: 20대 여성/남성, 30대 여성/남성, 시니어
- **커스텀 설정**: 선호 음료, 알레르기, 관심사, 식이 제한, 가격 민감도
- **실시간 동기화**: PC에서 설정 변경 → 스마트폰에 즉시 반영

### 3. CSS 오버레이
- **추천 배지**: 💚 선호 메뉴 하이라이트
- **재구매**: 🔁 최근 구매 이력 표시
- **알레르기 경고**: ⚠️ 알레르기 성분 주의
- **프로모션**: 🎁 맞춤형 할인 정보

### 4. 웹 기반 아키텍처
- **PC 관리 페이지** (`/admin`): 페르소나 설정 및 프로필 관리
- **스마트폰 AR 뷰** (`/`): 실시간 카메라 피드 + 오버레이
- **HTTPS**: 스마트폰 카메라 접근 권한 지원

## 시스템 요구사항

- Python 3.11 이상
- 웹 브라우저 (Chrome, Safari 권장)
- 웹캠 또는 스마트폰 카메라
- 네트워크 연결 (PC-스마트폰 동일 네트워크)

## 설치 및 실행

### 1. 의존성 설치

```bash
pip install flask flask-cors opencv-python numpy pillow paddlepaddle paddleocr pyopenssl
```

### 2. 서버 실행

```bash
python web_app.py
```

서버 시작 후 출력되는 주소를 확인하세요:
```
🚀 Flask 서버 시작...
📱 브라우저에서 https://localhost:5000 접속 (HTTPS)
💡 스마트폰에서도 접속 가능 (HTTPS 필수)

 * Running on https://127.0.0.1:5000
 * Running on https://192.168.x.x:5000
```

### 3. 접속

**PC에서 관리 페이지:**
```
https://localhost:5000/admin
```

**스마트폰에서 AR 뷰:**
```
https://192.168.x.x:5000/
```
(⚠️ HTTPS 자체 서명 인증서 경고 무시하고 진행)

## 사용 방법

### 1️⃣ PC에서 페르소나 설정

1. PC 브라우저에서 `https://localhost:5000/admin` 접속
2. 페르소나 선택 (또는 커스텀 설정):
   - 👩 20대 여성: 라떼, 패션, 뷰티
   - 👨 20대 남성: 아메리카노, 게임, IT
   - 👩‍💼 30대 여성: 육아, 가전, 건강
   - 👨‍💼 30대 남성: 자동차, 투자, 골프
   - 👴 시니어: 건강, 여행, 취미
   - ⚙️ 커스텀: 직접 설정
3. **"💾 저장 및 적용"** 클릭

### 2️⃣ 스마트폰에서 광고 촬영

1. 스마트폰 브라우저에서 `https://192.168.x.x:5000/` 접속
2. 상단에 현재 페르소나 정보 확인 (예: **20대 여성** | 라떼 | 패션 | 뷰티)
3. **카메라 선택** 후 **"카메라 시작"** 클릭
4. 광고판 촬영 → OCR 인식 → 개인화 오버레이 표시

### 3️⃣ 실시간 동기화 확인

- PC에서 페르소나 변경 → 저장
- 스마트폰 페이지 새로고침 (또는 다음 OCR 실행 시 자동 반영)
- 변경된 선호도에 맞는 새로운 오버레이 표시

## API 엔드포인트

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/` | 스마트폰 AR 뷰 |
| GET | `/admin` | PC 관리 페이지 |
| POST | `/api/process_frame` | OCR 처리 및 오버레이 생성 |

## 기술 스택

- **백엔드**: Flask, Flask-CORS
- **OCR**: PaddleOCR (PP-OCRv5_server_det, korean_PP-OCRv5_mobile_rec)
- **프론트엔드**: HTML5, CSS3, JavaScript (ES6+)
- **카메라**: WebRTC getUserMedia API
- **보안**: HTTPS (adhoc SSL)
- **이미지 처리**: OpenCV, NumPy, Pillow

## 문제 해결

### 스마트폰에서 카메라 접근 불가
- HTTPS로 접속했는지 확인 (`https://` 필수)
- 자체 서명 인증서 경고 무시하고 진행
- 브라우저 설정에서 카메라 권한 허용

### "저장 실패" 오류
- Flask 서버 재시작: `Ctrl+C` 후 `python web_app.py` 다시 실행
- 브라우저에서 관리 페이지 새로고침

### OCR 인식률 낮음
- 광고판에 가까이 다가가서 촬영
- 조명이 밝은 환경에서 촬영
- 텍스트가 선명하게 보이도록 초점 맞춤

### 페르소나 정보가 업데이트되지 않음
- 스마트폰 페이지 새로고침 (F5 또는 당겨서 새로고침)
- `config/user_profile.json` 파일 확인
